# Student Processing Dashboard

A pixel-perfect implementation of the USAF-SPC Digital Student Processing design, built using **React (Vite)** and **Tailwind CSS**.

## Live Links
- **Live Deployment:** - https://sithafal-spc-assessment.netlify.app/

## Features Implemented
- **Dynamic Multi-dropdown Filtering:** Synchronized array-filtering matrices that recalculate analytics metrics in real-time.
- **Dynamic Validation Hooks:** Custom native toast alerts preventing batch operations on fewer than 3 checked rows.
- **Dynamic File Downloader Compilation:** Custom runtime engine to cleanly parse and download selected indices to a structured CSV spreadsheet.
- **Tailwind Ecosystem:** Completely responsive compound layouts matching specified grid specifications.
